# Architecture Decision Records

This directory contains Deskleaf architecture decisions that should guide future feature work.

Use ADRs for decisions that are:
- Cross-cutting.
- Hard to reverse.
- Likely to affect multiple future features.
- Repeated often enough that agents need a stable rule.

Do not create ADRs for one-off implementation details.

## Template

```md
# ADR N: Title

Date: YYYY-MM-DD

## Status
Proposed | Accepted | Superseded

## Context

## Decision

## Consequences
```
